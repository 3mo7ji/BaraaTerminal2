# Baraa Terminal 2

مشروع Android جديد ومستقل. يستضيف ملفات واجهة BotDock الثابتة عبر خادم HTTP مدمج على المنفذ 3000.

## التشغيل
1. افتح المشروع في Android Studio أو ارفعه إلى GitHub.
2. ابنِ APK عبر Build > Build APK أو عبر GitHub Actions.
3. ثبّت التطبيق.
4. اختر مجلد BotDock الذي يحتوي `index.html`.
5. اضغط «تشغيل BotDock».
6. افتح `http://127.0.0.1:3000` في متصفح الهاتف.

## الصلاحيات
- اختيار المجلد يتم عبر منتقي ملفات Android مع حفظ إذن الوصول.
- التطبيق يطلب إذن الإشعارات على Android 13+.
- زر «السماح بالعمل في الخلفية» يفتح إعداد استثناء تحسين البطارية.
- أثناء تشغيل الخادم يستخدم التطبيق Foreground Service وPartial WakeLock.

## حدود النسخة
هذه النسخة لا تحتوي Node.js ولا تشغّل Express أو `npm install` أو JavaScript الخلفي. إنها تخدم ملفات HTML/CSS/JS والصور فقط، وتوفر `/api/health`. إذا كان BotDock يعتمد على وظائف Node خلفية، فهذه النسخة لا تشغّلها بعد.
الخدمة تستمع على `0.0.0.0:3000` لتسمح بالوصول من نفس الهاتف أو الشبكة المحلية؛ لا تعرض المنفذ للإنترنت العام دون إضافة حماية ومصادقة وHTTPS.
أندرويد قد يوقف الخدمة رغم إعدادات البطارية؛ لا يوجد ضمان تشغيل 24/7.
